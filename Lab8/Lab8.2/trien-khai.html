Deployment Guide

Triển khai Website lên Internet

1 Chuẩn bị mã nguồn dự án

Đảm bảo toàn bộ cấu trúc thư mục gồm file index.html, style.css và thư mục ảnh images/ sử dụng đường dẫn tương đối (ví dụ: ./images/tea-main.jpg) để khi đưa lên máy chủ không bị lỗi hiển thị ảnh.

2 Triển khai qua GitHub Pages (Miễn phí)

Tạo một repository mới trên GitHub và tải toàn bộ mã nguồn lên:

git init
git add .
git commit -m "Deploy Tea Station Website"
git branch -M main
git remote add origin https://github.com/username/tea-station.git
git push -u origin main

Vào Settings > Pages trên GitHub, tại mục Branch chọn main và nhấn Save. Sau 1 phút trang web sẽ hoạt động trực tuyến.

3 Triển khai qua Vercel / Netlify

Truy cập vào trang chủ Vercel.com hoặc Netlify.com, đăng nhập bằng tài khoản GitHub, chọn repository tea-station và nhấn Deploy. Hệ thống sẽ tự động gán tên miền HTTPS miễn phí để nộp bài hoặc chia sẻ.
